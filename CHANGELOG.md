# Changelog

## [0.1.0] - 2026-06-25

### Added

- Local Markdown decision entries with confidence and review-date fields.
- Safe default storage outside the repository checkout.
- Input validation and overwrite protection.
- `due` and `review` commands for a basic decision-to-outcome lifecycle.
- Fictional full-lifecycle example and data/privacy guidance.

### Scope

This is a lightweight personal workflow utility. It is not a decision-quality analytics platform, a forecasting system, or legal, financial, medical, employment, or psychological advice.
